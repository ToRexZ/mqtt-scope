Auto-subscribed topic tree

Connect and the tree fills itself. Every topic level shows live message and topic counts, and changed topics flash. It stays smooth with tens of thousands of topics. Filter by text or MQTT wildcard, even inside payloads.

Read large messages comfortably

A collapsible JSON tree that highlights what changed since the last message, syntax-highlighted text, raw and hex views, history, and a Held mode that stops the view from jumping while you read. Search filters a multi-megabyte document down to the matching branches.

See exactly what changed

A structural diff lists every added, removed and changed field between two messages, path by path.

Plot any value, live

Pick numbers from any topic or JSON field, from several topics at once, and give each series a readable alias. Up to eight series per plot, a live time window, hover values, and CSV export.

Publish safely, again and again

Save the messages you send most and fire them with one click. The publish target never silently follows your clicks once you have edited a message, retained publishes ask first, and double clicks never send twice.

Questions

Is MQTT Scope free?

Yes. MQTT Scope is free and open source under the MIT license, for Linux, Windows and macOS.

Is MQTT Scope an alternative to MQTT Explorer?

Yes. Like MQTT Explorer it subscribes to everything and shows the broker as a live topic tree. It adds a large-message inspector with a structural diff, live plots of any JSON field with aliases, a library of saved messages, several brokers at once (one per window) and safety guards for publishing to live systems.

Which MQTT versions and transports does it support?

MQTT 3.1.1 and MQTT 5.0 over TCP (mqtt://), TLS (mqtts://, with custom CA and client certificates), WebSocket (ws://) and secure WebSocket (wss://), with username and password authentication.

Can it handle large JSON messages and busy brokers?

Yes. Multi-megabyte JSON messages open instantly because the tree renders on demand, search filters a large document down to the matching branches, and the virtualised topic tree stays smooth with tens of thousands of topics.

Can I plot MQTT values?

Yes. Pick numbers from any topic or JSON field, from several topics at once, and give each series an alias. Plots update live and can be exported as CSV.

Does it work with VDA5050 and robot fleets?

Yes. It was built against VDA5050 robot brokers: state, visualization, order and factsheet messages, 64-bit ids kept exact, and saved instant actions you can send with one click.

How do I install it on Linux?

Download the AppImage or tar.gz from the latest release. On Arch Linux, build the mqtt-scope-bin package from the repository's packaging/aur folder with makepkg -si.
